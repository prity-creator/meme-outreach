# Northwind Bookkeeping — meme outreach company file

> Made-up example. Northwind Bookkeeping, its clients and its people are fictional. This is what the company-setup skill produces for a real company.

This skill holds data for the meme-outreach plugin. It doesn't make memes by itself.

- `brief.md` — what Northwind does, who it sells to, pains, proof points, voice, off-limits
- `meme-bank.md` — 20 pain-to-meme rows with captions and casual questions

To make a meme for a Northwind prospect, use the `make-memes` skill from the meme-outreach plugin (`/meme-outreach:make-memes`) and say it's a Northwind prospect. It reads both files from this folder.
